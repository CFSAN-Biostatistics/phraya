# Phraya Long-Read Benchmark — 2026-10-01

## Summary

**Benchmark executed successfully on Reedling2 HPC.** After implementing chunked WFA for `Strategy::LongRead`, phraya alignment succeeds at realistic ONT error rates (12%), matching minimap2's placement accuracy.

**Test scope**: n=10 reads, 8-20 kb, synthetic 5 Mb reference, two discrete error rates (1%, 12%). Single seed. This demonstrates feasibility, not a comprehensive error-rate sweep.

## Implementation: Chunked WFA

### Problem
`Strategy::LongRead` routed to unbanded `wfa_extend()` on the full read (executor.rs). At 12% ONT error:
- Expected edit distance ~1,200-2,400 for 10-20 kb reads
- `default_max_s_cap ≈ 768` (512 MB wavefront memory limit)
- WFA abandoned all reads (`no_alignment=10`)

### Fix
Added `extend_chains_longread()` in `executor.rs` that:
1. Splits each read into 2 kb non-overlapping chunks (2000 edits at 1% → well under cap)
2. Extends each chunk independently via WFA
3. Tracks running target position across chunks (`aln.target_end` → next chunk's anchor) for indel-drift-aware projection
4. Concatenates per-chunk CIGARs into single alignment
5. Uses strategy-aware threshold: `LongRead=0.80` (vs `Balanced/Sensitive=0.95`) via new `score_threshold()` function

### Files Changed
- `phraya-align/src/executor.rs` — `extend_chains_longread()`, `score_threshold()`, `LongRead` branch in `extend_chains()`
- `phraya-align/src/lib.rs` — Export `score_threshold`
- `phraya-io/src/queries.rs` — `write_queries()` and `write_cross_space_queries()` now take `threshold: f64`
- `phraya-cli/src/main.rs` — Pass strategy-aware threshold at all call sites

## Measured Results

### Test Data (Reedling2 HPC)
- Reference: 5 Mb synthetic genome
- Reads: 10 reads, 8-20 kb each (ONT R10.4: 12% error, 70% indels)
- Generated by: `gen_synthetic_long.py`

### Results After Chunked WFA Fix

| Aligner | Read Error | PA | Wall (s) | Peak RSS (MB) | Notes |
|---------|-----------|----|---------|---------------|-------|
| phraya-longread | 12% | 10/10 (100%) | 8.85 | ~1470 | ✅ Chunked WFA succeeds |
| minimap2-ont | 12% | 10/10 (100%) | 0.31 | ~117 | Reference baseline |

Before the fix:
| Aligner | Read Error | PA | Wall (s) | Notes |
|---------|-----------|----|---------|-------|
| phraya-longread | 12% | 0/10 (0%) | 4.79 | WFA abandons (no_alignment=10) |
| phraya-longread | 1% | 10/10 (100%) | 7.64 | WFA succeeds under cap |

Both aligners achieve 100% placement accuracy at 12% error. Phraya is ~28× slower than minimap2 (8.85s vs 0.31s) with ~12× higher RSS (1470 MB vs 117 MB), reflecting the Rust WFA implementation vs minimap2's optimized C.

## Performance Notes
- phraya wall time (8.85s for 10 reads) includes plan creation overhead + alignment. Actual alignment is ~7-8s.
- minimap2's 0.31s includes index build. Its pure alignment time is even faster.
- RSS measured via `resource.getrusage(RUSAGE_CHILDREN)` (cumulative peak, not per-process).
